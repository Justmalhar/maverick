## Task 0.1 — Fix Terminal-Mode PTY-per-leaf binding
- Reproduce: split a terminal; confirm leaves show no output (hardcoded `ptyId: workspace.id`).
- Each `TerminalView` leaf must spawn its own PTY and bind to the `pty_N` id Rust returns.
- `SplitGrid` tracks `leafId → ptyId`; writes/resizes/kills target the leaf's real pty.
- Files: `src/components/editor/terminal/**`, `src/lib/providers/**`, `src/hooks/usePty.ts`.
- Tests: split → each leaf gets a distinct pty id; keystroke routes to focused leaf only.

## Task 0.2 — Register missing git write commands
- Cross-check `sidecar/git-module.ts` exports vs commands registered in `src-tauri/src/lib.rs`.
- Register the missing ones (checkout, blame, cherry_pick, stash_apply/pop/drop, conflicts,
  resolve_conflict, +any 9th) and add their `#[tauri::command]` wrappers in
  `src-tauri/src/commands/git.rs`.
- Tests: each command round-trips through the loopback JSON-RPC fixture (`cargo test`).

## Task 0.3 — Render shell chrome in Workbench
- Mount `StatusBar`, `ActivityBar`, `Panel` in `src/components/workbench/Workbench.tsx`.
- Wire `NotificationBell` + `CaffeinateToggle` into `StatusBar`.
- Files: `src/components/workbench/**`, `statusbar/**`, `activitybar/**`, `panel/**`.
- Tests: Workbench renders all three regions; bell + caffeine toggle are present/queryable.

## Task 0.4 — PTY lifecycle hardening
- Kill PTYs on `workspace.destroy` (no leaked processes).
- Batch xterm writes in a 16ms RAF window.
- Bounded LRU xterm renderer pool for inactive groups.
- Files: `src-tauri/core/src/pty/**`, `src/lib/providers/xterm-provider.ts`,
  `sidecar/process-manager.ts`.
- Tests: destroy kills pty; RAF batching coalesces bursts; LRU evicts beyond cap.

## Task 0.5 — Windows shell selection (PowerShell default + cmd + WSL)
- Add `defaultShell: 'powershell' | 'cmd' | 'wsl'` to `maverick.json` schema in
  `sidecar/config-loader.ts` (default `'powershell'` on Windows) + mirror type in
  `src/lib/ipc.ts` and `sidecar/types.ts`.
- Shell resolution in `sidecar/process-manager.ts` (+ Rust spawn args in
  `src-tauri/core/src/pty/**`): map to `pwsh`/`powershell.exe`, `cmd.exe`, `wsl.exe`;
  detect which are installed; degrade gracefully if `pwsh` absent (fall back to
  `powershell.exe`), and hide WSL if not installed.
- UI: shell picker in the new-terminal/split affordance (`src/components/editor/terminal/**`)
  and Settings → Terminal (`src/panels/settings/**`). Use shadcn primitives + tokens only.
- Tests (must cover ALL three shells): resolution logic per shell, fallback when `pwsh`
  missing, WSL hidden when absent, persisted `defaultShell` honored on spawn.

## Task 0.6 — Windows worktree verification
- Verify `sidecar/worktree-manager.ts` create/destroy/list with Windows path separators and
  the `.maverick/worktrees/` base; files-to-copy works; no symlink assumptions.
- Tests: worktree add/remove on Windows-style paths; files-to-copy copies `.env`.
